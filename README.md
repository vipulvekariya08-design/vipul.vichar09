# Vipul Vekariya Literary Website — Final Version 3

## GitHub Pages
1. Create a free GitHub repository.
2. Upload everything in this folder.
3. Settings → Pages → Deploy from branch → main → /root.
4. Save and open your GitHub Pages URL.

## YOUR PHOTO AND LOGO
Replace/add:
- assets/logo.png
- assets/vipul-photo.jpg

Keep these exact names.

## ADD A NEW WRITING
Copy `writings/raat-mein-apna-shahar/` to a new folder.
Edit its `content.json`.
Add the corresponding entry to `data/writings.json`.
The reader URL is:
`reader.html?id=YOUR-ID`

## AFTER YOU KNOW YOUR GITHUB URL
Replace YOUR-USERNAME and YOUR-REPOSITORY in robots.txt and sitemap.xml.
